# ระบบจัดตารางเรียน การสอน และการใช้พื้นที่อัตโนมัติ

คณะศึกษาศาสตร์ มหาวิทยาลัยการกีฬาแห่งชาติ วิทยาเขตกระบี่ ภาคเรียนที่ 2/2569

## ไฟล์

| ไฟล์ | คำอธิบาย |
|---|---|
| `index.html` | ระบบต้นฉบับ ยังไม่นำเข้าข้อมูล |
| `index_with_data.html` | ระบบที่นำเข้าข้อมูล Excel ของโจทย์แล้ว เปิดแล้วจัดตารางอัตโนมัติ |
| `data/ข้อมูลรายวิชา_ver2.xlsx` | ไฟล์ข้อมูลรายวิชาจากโจทย์ |
| `data/แม่แบบรายวิชา.xlsx` | ไฟล์แม่แบบเปล่าสำหรับนำเข้า |
| `src/` | source code แยกไฟล์ |

## วิธีใช้

1. เปิด `index.html` แล้วเลือกไฟล์ Excel รายวิชา
2. ตรวจผลข้อมูลก่อนคำนวณ แล้วกดยืนยัน
3. ตั้ง seed และจำนวนรอบ แล้วกดเริ่มจัดตาราง
4. ดูผลตรวจ 11 เงื่อนไข ดูตารางรายกลุ่ม รายผู้สอน รายห้อง/สนาม และส่งออก CSV / Excel / PDF

## Source

- `src/engine.js` แปลงไฟล์ ตรวจข้อมูล จัดตาราง (Greedy + Heuristic + seed + ซ่อมแบบ plan-act-check) และตรวจผล
- `src/app.js`, `src/body.html`, `src/app.css` หน้าจอ
- `src/features.js` แอนิเมชัน AI (Plan-Act-Repair-Check), ลากย้ายวิชาพร้อมตรวจเงื่อนไข, หลักฐานเชิงตัวเลข (ablation 4 วิธี + stress test), QR Code และหน้ามือถือ
- `src/build.py` รวมเป็น `index.html` (`python build.py data.xlsx` จะสร้าง `index_with_data.html` ด้วย)
- `src/test.js` ทดสอบ engine ด้วย Node.js
