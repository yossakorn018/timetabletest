  1. กรอก ชื่อผู้ใช้ และ รหัสผ่าน กดรูปตา 👁 เพื่อดูรหัสที่พิมพ์ แล้วกด เข้าสู่ระบบ

หน้าเข้าสู่ระบบ

2นำเข้าข้อมูล (ผู้ดูแลระบบ)

  1. เมนู 1 นำเข้าข้อมูล → ลากไฟล์ Excel มาวาง หรือกด เลือกไฟล์
    รูปแบบไฟล์: แยกชีตตามชั้นปี คอลัมน์ ที่ | รหัสวิชา | ชื่อรายวิชา | หน่วยกิต เช่น 3(2-2-5) | กลุ่มวิชา | อาจารย์ผู้สอน | - | หมายเหตุ (* = ผู้บริหาร) — กด ⬇ ไฟล์แม่แบบ เพื่อดาวน์โหลดตัวอย่าง
  2. ไม่มีไฟล์? กดปุ่ม ชุดข้อมูลตัวอย่าง เล็ก (ปี 1) / กลาง (โจทย์จริง) / ใหญ่ (×3 วิทยาเขต) หรือดาวน์โหลดไฟล์ตัวอย่างทั้ง 3 ไฟล์จากลิงก์ใต้ปุ่ม
  3. รองรับไฟล์ ชุดข้อมูล JSON ด้วย: กด ส่งออกชุดข้อมูลปัจจุบัน (.json) เพื่อเก็บไว้ แล้วนำเข้ากลับได้ทุกเมื่อ
  4. ถ้าคำชี้แจงเปลี่ยน เปิด "ตั้งค่าเงื่อนไขจากคำชี้แจง" แก้จำนวนกลุ่ม ห้องประจำ สนาม เวลาล็อก หรือรายชื่อผู้บริหาร แล้วกด บันทึกการตั้งค่า
  5. ตรวจ สรุปข้อมูล และ ผลตรวจก่อนคำนวณ: ⛔ ต้องแก้ก่อน · ⚠️ ควรตรวจ · ℹ️ แจ้งให้ทราบ (มีวิธีแก้บอกไว้ทุกข้อ)
    ตรวจ เช่น ไฟล์ว่าง/ผิดรูปแบบ · รหัสวิชาซ้ำ · ไม่มีชื่อวิชา · ไม่มีผู้สอน · หน่วยกิตอ่านไม่ได้ · หาสนามไม่เจอ · ชั่วโมงเกินเวลาที่มี · ที่นั่งวิชาเลือกไม่พอ
  6. กด ยืนยันและบันทึกข้อมูล →

หน้านำเข้าข้อมูล: ลากวางไฟล์ / ชุดตัวอย่าง / สรุปและผลตรวจข้อมูล

ระบบแปลงรายวิชาเป็น ตอนเรียน อัตโนมัติ: ทฤษฎีใช้ห้องประจำกลุ่ม · นวัตกรรมฯ ใช้ห้องคอม · ทักษะกีฬาใช้ห้องเรียน+สนามพร้อมกัน · ปฏิบัติการวิชาชีพเรียนรวมทั้งชั้นปี · วิชาเลือกทุกวิชาในชุดเดียวกันเปิดพร้อมกัน · ชั้นปีที่ 4 ฝึกสอนทั้งภาค ไม่จัดคาบ

3จัดตาราง

  1. เมนู 2 จัดตาราง ใส่ Seed (ค่าเริ่มต้นการสุ่ม ใช้ค่าเดิมได้ผลเดิมทุกครั้ง) และ จำนวนรอบ (แนะนำ 20–30)
  2. กด ▶ เริ่มจัดตาราง ดูแถบความคืบหน้า กด ■ ยกเลิก ได้ตลอดเวลา ระบบจะใช้ผลที่ดีที่สุดที่ได้
  3. ดู ตารางเปรียบเทียบกับวิธีพื้นฐาน และ ประวัติการรัน กด "ใช้ผลนี้" เพื่อสลับไปใช้ผลรอบอื่น
  4. กด ▶ เล่น ในกล่อง 🎬 เพื่อดูการทำงานของ AI ทีละขั้น: ① Plan วางแผน → ② Act วาง → ③ Repair ซ่อม → ④ Check ตรวจ

หน้าจัดตาราง และภาพเคลื่อนไหวการทำงานของ AI

💡 หลักการ: จัดวิชาที่มีข้อจำกัดมากก่อน (วิชาเลือก → เรียนรวม → สอนร่วม → ทักษะกีฬา → ห้องคอม → ทฤษฎี) เลือกช่องที่กระจายภาระดีที่สุด ถ้าวางไม่ลงจะย้ายวิชาที่ชนออกแล้วจัดใหม่ และเก็บผลดีที่สุดจากหลาย seed

4ตรวจผล

เมนู 3 ตรวจผล แสดงผลตัวตรวจอิสระ 11 ข้อ ✅ ผ่าน / ❌ ไม่ผ่าน พร้อมรายการจุดที่ผิด

  1. คาบครบตามหน่วยกิต (บรรยาย+ปฏิบัติ)
  2. ไม่จัดในคาบพัก/พบอาจารย์ที่ปรึกษา/กิจกรรม
  3. ผู้สอนไม่ซ้อนคาบ
  4. ห้อง/สนามไม่ซ้อนคาบ
  5. กลุ่มเรียนไม่ซ้อนคาบ
  6. ผู้บริหารไม่สอนอังคารคาบ 1–4
  7. ใช้ห้องถูกประเภท
  8. วิชาสอนร่วม ผู้สอนอยู่ครบ
  9. ทักษะกีฬา/วิชาเลือก เรียนคาบติดกัน
  10. วิชาเลือกในชุดเดียวกันเวลาเดียวกัน
  11. ความจุห้องเพียงพอ

ผลตรวจ 11 เงื่อนไข

5ดูตาราง แก้ไข และส่งออก

  1. เมนู 4 ดูตาราง/ส่งออก เลือกมุมมอง: ตารางเรียน (กลุ่ม) / ตารางสอน (ผู้สอน) / ตารางการใช้พื้นที่ (ห้อง/สนาม) ค้นหาชื่อได้
  2. แก้ไขด้วยการลากวาง: จับช่องวิชาแล้วลากไปช่องใหม่ — เขียว = วางได้ แดง = ชน ป้ายบอกเหตุผล เช่น "กลุ่ม 1/1 เรียน มศ 041017 อยู่" · ระบบตรวจ 11 ข้อใหม่ทุกครั้ง · กด ↶ ย้อนกลับ ได้
  3. ส่งออก: ส่งออก CSV ส่งออก Excel (ทุกกลุ่ม/ผู้สอน/ห้อง) พิมพ์ / PDF
    ตอนพิมพ์: Layout = Landscape · ติ๊ก Background graphics · เอา Headers and footers ออก
  4. 📱 QR Code ให้นักศึกษา/อาจารย์สแกนดูตารางบนมือถือ (ใช้ได้เมื่อเปิดผ่านลิงก์ GitHub Pages) กด "แสดง QR ทุกกลุ่ม" เพื่อพิมพ์แจก

ตารางเรียนรายกลุ่ม สีบอกประเภทวิชา

ตารางและการลากย้ายถูกบันทึกอัตโนมัติ รีเฟรชหน้าแล้วยังอยู่ (เก็บเฉพาะ seed และรายการย้าย จึงคำนวณตารางเดิมกลับมาได้ทุกครั้ง)

6รายงานและหลักฐาน

  • 5 รายงาน ภาระสอนของผู้สอน (นับวิชาสอนร่วมให้ทุกคน) และอัตราการใช้ห้อง/สนาม
  • 6 หลักฐาน/ทดสอบ
    • เปรียบเทียบ 4 วิธี: รันหลาย seed แล้วนับว่าแต่ละวิธีจัดครบกี่ % — แสดงว่าการ "จัดวิชายากก่อน" และ "ซ่อม" ช่วยจริง
    • Stress test: ข้อมูลใหญ่ขึ้น ×1–×10 วัดเวลา ความถูกต้อง หน่วยความจำ

หน้าหลักฐานเชิงตัวเลข

7จัดการผู้ใช้ (ผู้ดูแลระบบ)

  • สร้างผู้ใช้: กรอกชื่อผู้ใช้ รหัสผ่าน เลือกบทบาท และผูกกับอาจารย์/กลุ่ม → + สร้างผู้ใช้
  • สร้างหลายบัญชี: สร้างบัญชีอาจารย์ทุกคน (t01, t02, …) สร้างบัญชีทุกกลุ่มเรียน (g1-1, g1-2, …)
  • แก้ไข: กด ✏️ แก้ไข เปลี่ยนชื่อผู้ใช้ ชื่อ บทบาท การผูก หรือรหัสผ่าน — เปลี่ยนรหัสต้องใส่รหัสผู้ดูแลยืนยันก่อน
  • 🔔 คำขอ: อนุมัติ/ปฏิเสธการสมัคร และตั้งรหัสใหม่ให้ผู้ที่ลืมรหัส (เมนูมีวงแดงบอกจำนวน)
  • ส่งออก/นำเข้ารายชื่อผู้ใช้เป็น JSON เพื่อย้ายไปเครื่องอื่น

หน้าจัดการผู้ใช้

8สำหรับอาจารย์ / นักศึกษา

  1. เข้าสู่ระบบด้วยบัญชีที่ได้รับ (เช่น t10 หรือ g1-1)
  2. ระบบเปิดหน้า ตารางสอนของฉัน / ตารางเรียนของฉัน ทันที และแสดงรายการวิชาของตัวเองด้านล่าง
  3. ส่งออก Excel / CSV / PDF หรือสร้าง QR ได้เฉพาะตารางของตัวเอง
  4. นักศึกษาชั้นปีที่ 4 จะเห็นข้อความ "ฝึกปฏิบัติการสอนในสถานศึกษาตลอดภาคเรียน"

มุมมองของอาจารย์: เห็นเฉพาะวิชาที่สอน

9ปัญหาที่พบบ่อย

อาการวิธีแก้
กดเลือกไฟล์แล้วขึ้น "โหลดไลบรารีอ่าน Excel ไม่ได้"ตรวจอินเทอร์เน็ต แล้วรีเฟรชหน้า (Ctrl+F5)
ปุ่ม "ยืนยันและบันทึกข้อมูล" กดไม่ได้มีข้อ ⛔ ในผลตรวจข้อมูล ทำตาม "วิธีแก้" ที่บอกไว้ หรือแก้การตั้งค่า
จัดตารางแล้วยังขาดบางคาบเพิ่มจำนวนรอบ หรือกดสุ่ม seed แล้วจัดใหม่ ดูรายวิชาที่ค้างในกล่องบันทึกด้านล่างตารางเปรียบเทียบ
ลากวิชาแล้ววางไม่ได้ช่องเป็นสีแดงแปลว่าชน ชี้ค้างเพื่อดูเหตุผล
พิมพ์ PDF แล้วไม่มีสีติ๊ก Background graphics ในหน้าต่างพิมพ์
สแกน QR แล้วเปิดไม่ได้ต้องเปิดระบบผ่านลิงก์ GitHub Pages ไม่ใช่ไฟล์ในเครื่อง
บัญชีที่สร้างไว้ไม่มีในอีกเครื่องบัญชีเก็บในเบราว์เซอร์ของแต่ละเครื่อง ใช้ "ส่งออก/นำเข้ารายชื่อผู้ใช้ (JSON)"
ลืมรหัสผู้ดูแลระบบให้ผู้ดูแลอีกคนตั้งรหัสใหม่ หรือล้างข้อมูลเว็บไซต์ในเบราว์เซอร์เพื่อกลับไปใช้ admin / admin1234
ความปลอดภัย: รหัสผ่านเก็บเป็น SHA-256 + salt (ไม่เก็บรหัสจริง) · การตรวจสิทธิ์ทำในเบราว์เซอร์ หากใช้งานจริงควรต่อฐานข้อมูลออนไลน์ที่ตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์ (เช่น Supabase RLS)
